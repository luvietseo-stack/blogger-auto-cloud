01

Chuẩn Bị Trang Blogger & Lấy Blog ID

Tìm mã định danh duy nhất của blog để robot biết chính xác địa chỉ cần đăng bài.

  1. Truy cập vào trang quản trị Blogger: https://www.blogger.com.
  2. Tạo một blog mới (nếu chưa có) hoặc chọn đúng blog bạn muốn cài đặt tự động hóa.
  3. Nhìn lên thanh địa chỉ của trình duyệt web (URL), bạn sẽ thấy một dãy số dài ở sau chữ /blog/posts/ hoặc /blog/settings/.
  4. Dãy số đó chính là BLOGGER_BLOG_ID của bạn. Hãy copy dãy số này lưu vào Notepad.

02

Bật Blogger API & Lấy Google OAuth (Client ID, Secret, Refresh Token)

Cấp quyền hợp pháp cho robot thay mặt bạn đăng bài và đặt lịch hẹn giờ lên Blogger.

  1. Truy cập Google Cloud Console: https://console.cloud.google.com và đăng nhập cùng tài khoản quản trị Blog.
  2. Bấm Select a project ➔ New Project ➔ Đặt tên Blogger-Auto-Cloud ➔ Nhấn Create.
  3. Gõ tìm kiếm Blogger API v3 ➔ Chọn kết quả và nhấn nút Enable (Bật).
  4. Ở menu bên trái, vào APIs & Services ➔ OAuth consent screen (Màn hình đồng ý OAuth):
    • Chọn External (Bên ngoài) ➔ Bấm Create.
    • Điền tên ứng dụng (vd: Blogger Cloud Poster) và email của bạn ở các ô bắt buộc.
    • Bấm Save and Continue cho đến khi hoàn tất.
    • Tại mục Test users (Người dùng thử nghiệm): bấm + Add Users và thêm chính địa chỉ Gmail của bạn vào.
  5. Vào mục Credentials (Thông tin xác thực):
    • Bấm + Create Credentials ➔ Chọn OAuth client ID.
    • Mục Application type: chọn Desktop app.
    • Bấm Create. Bạn sẽ nhận được Client ID và Client Secret. Hãy lưu lại.
  6. Lấy Refresh Token:
    • Sử dụng công cụ Google OAuth 2.0 Playground (hoặc script lấy token).
    • Phạm vi quyền (Scope) tích chọn: https://www.googleapis.com/auth/blogger.
    • Cấp quyền xong, bạn sẽ nhận được mã GOOGLE_REFRESH_TOKEN (bắt đầu bằng 1//0...).

03

Lấy Google Gemini API Key (Bộ Não Viết Bài Miễn Phí)

Trí tuệ nhân tạo Gemini 2.5 Flash thông minh sẽ tự động sinh nội dung chuẩn SEO 1500+ từ.

  1. Truy cập trang Google AI Studio: https://aistudio.google.com/app/apikey.
  2. Đăng nhập bằng tài khoản Google của bạn.
  3. Bấm nút Create API Key (Tạo khóa API).
  4. Chọn đúng dự án Google Cloud bạn vừa tạo ở Bước 2.
  5. Bấm Create API Key in existing project.
  6. Copy chuỗi khóa API (bắt đầu bằng AIzaSy... hoặc AQ...) lưu lại. Đây chính là GEMINI_API_KEY.
Ảnh minh họa 03
Giao Diện Tạo Khóa Gemini API Key Miễn Phí Tại AI Studio

(Cửa sổ tạo API Key và sao chép chuỗi mã API bí mật)

✨
Mẹo xoay vòng khóa (Key Pool): Bạn có thể tạo 3 đến 5 khóa Gemini API Key từ các tài khoản Gmail khác nhau và điền cách nhau bằng dấu phẩy (KEY_1,KEY_2,KEY_3) vào biến GEMINI_API_KEYS để hệ thống tự động xoay vòng dự phòng, không bao giờ lo gián đoạn vì quá tải!
04

Tạo Telegram Bot & Nhóm Nhận Báo Cáo Tự Động

Mỗi khi có bài viết được lên lịch hay gửi Indexing thành công, điện thoại sẽ báo ngay lập tức.

  1. Mở ứng dụng Telegram trên điện thoại hoặc máy tính.
  2. Tìm kiếm bot chính thức của Telegram: @BotFather.
  3. Gõ lệnh /newbot, đặt tên cho bot (vd: Blogger LuViet Bot) và đặt username kết thúc bằng bot (vd: my_blogger_post_bot).
  4. BotFather sẽ gửi một chuỗi token dạng: 8480459173:AAHhSTEG.... Lưu lại làm TELEGRAM_BOT_TOKEN.
  5. Tạo một nhóm Telegram mới (vd: Báo Cáo Blogger Tự Động) và thêm con Bot vừa tạo vào nhóm.
  6. Thêm bot @RawDataBot hoặc @userinfobot vào nhóm để lấy số Chat ID của nhóm (dãy số âm bắt đầu bằng dấu trừ, ví dụ: -5074952407 hoặc -100...). Lấy xong Chat ID, bạn có thể xóa bot lấy ID ra khỏi nhóm.

05

Cấu Hình Google Sheets (Kho Đề Tài & Webhook Báo Cáo)

Nơi nhập hàng trăm tiêu đề bài viết và tự động đổi màu xanh khi bài viết xuất bản thành công.

  1. Mở bảng tính Google Sheets kế hoạch bài viết. Chuẩn hóa tiêu đề cột từ Cột A đến Cột I:
    • Cột A: Số Thứ Tự (STT)
    • Cột B: Tiêu Đề Bài Viết
    • Cột C: Từ Khóa SEO Chính
    • Cột D: Ý Định Tìm Kiếm (Search Intent)
    • Cột E: Nhóm Chuyên Mục (Labels, vd: dich-vu, tin-tuc)
    • Cột F: Link Ảnh Tùy Chọn (Để trống robot sẽ tự sinh Thumbnail Doanh Nhân YouTube)
    • Cột G: Trạng Thái (Robot tự cập nhật: Đã lên lịch hoặc Đã đăng và tô màu xanh lá)
    • Cột H: Ngày Lên Lịch / Xuất Bản
    • Cột I: Link Bài Viết Thực Tế
  2. Bấm Chia sẻ (Share) ở góc trên bảng tính ➔ Quyền truy cập chung: chọn Bất kỳ ai có đường liên kết ➔ Chọn quyền Người xem ➔ Sao chép link này làm GOOGLE_SHEET_URL.
  3. Cài đặt Webhook cập nhật trạng thái tự động:
    • Trên menu Google Sheets, bấm Tiện ích mở rộng (Extensions) ➔ Apps Script.
    • Dán mã nguồn file google_sheets_webhook.js vào rồi nhấn biểu tượng Lưu (Save).
    • Bấm Triển khai (Deploy) ➔ Bản triển khai mới (New deployment):
      • Loại triển khai: Ứng dụng web (Web app).
      • Thực thi dưới dạng: Tôi (Tài khoản của bạn).
      • Ai có quyền truy cập: Bất kỳ ai (Anyone).
    • Bấm Triển khai ➔ Copy đường link Web App có đuôi kết thúc bằng /exec lưu làm GOOGLE_SHEET_WEBHOOK_URL.

06

Cấu Hình Google Indexing API (Lập Chỉ Mục Siêu Tốc)

Tự động bắn URL bài viết đã Live lên thẳng Google Bot để bài viết xuất hiện trên Google chỉ sau vài phút.

  1. Quay lại Google Cloud Console: https://console.cloud.google.com.
  2. Tìm kiếm Web Search Indexing API ➔ Bấm vào và nhấn Enable (Bật).
  3. Vào mục IAM & Admin ➔ Service Accounts (Tài khoản dịch vụ) ➔ Bấm + Create Service Account.
    • Đặt tên: blogger-indexing-bot ➔ Nhấn Create and Continue ➔ Nhấn Done.
    • Copy địa chỉ email robot dạng: blogger-indexing-bot@du-an.iam.gserviceaccount.com.
  4. Bấm vào email robot vừa tạo ➔ Chuyển sang tab Keys (Khóa) ➔ Bấm Add Key ➔ Create new key ➔ Chọn loại JSON ➔ Nhấn Create.
    • File đuôi .json sẽ tải về máy tính. Mở file bằng Notepad và copy toàn bộ nội dung bên trong.
  5. Phân quyền trong Google Search Console:
    • Truy cập Google Search Console của website Blogger của bạn.
    • Vào Cài đặt (Settings) ➔ Người dùng và quyền (Users and permissions).
    • Bấm Thêm người dùng (Add user) ➔ Dán email robot Service Account ở trên vào ➔ Phân quyền: Chủ sở hữu (Owner) ➔ Nhấn Thêm (Add).

07

Fork Mã Nguồn & Cài Đặt 9 Khóa Bí Mật Vào GitHub Secrets

Lưu trữ an toàn tuyệt đối các thông tin đăng nhập, bảo mật 100% trên hạ tầng của GitHub.

  1. Đăng nhập tài khoản GitHub: https://github.com.
  2. Truy cập vào kho lưu trữ mã nguồn hệ thống và nhấn nút Fork về tài khoản cá nhân.
  3. Trên kho mã nguồn cá nhân, bấm vào tab Settings trên thanh menu.
  4. Ở cột bên trái, vào mục Secrets and variables ➔ chọn Actions.
  5. Bấm nút xanh New repository secret và lần lượt tạo đúng 9 biến sau:
Tên Secret (Gõ chính xác) Giá trị cần điền vào
BLOGGER_BLOG_ID Dãy số ID blog lấy ở Bước 1.
GEMINI_API_KEY Khóa Gemini API lấy ở Bước 3.
GOOGLE_CLIENT_ID OAuth Client ID lấy ở Bước 2 (...apps.googleusercontent.com).
GOOGLE_CLIENT_SECRET OAuth Client Secret lấy ở Bước 2.
GOOGLE_REFRESH_TOKEN Refresh Token Blogger lấy ở Bước 2 (bắt đầu bằng 1//0...).
GOOGLE_SHEET_URL Đường link chia sẻ file Google Sheets ở Bước 5.
GOOGLE_SHEET_WEBHOOK_URL Đường link Web App Apps Script đuôi /exec ở Bước 5.
TELEGRAM_BOT_TOKEN Chuỗi Token bot từ @BotFather ở Bước 4.
TELEGRAM_CHAT_ID Dãy số Chat ID nhóm nhận báo cáo ở Bước 4 (ví dụ: -5074952407).
INDEXING_SERVICE_ACCOUNT_JSON Toàn bộ nội dung file JSON Service Account ở Bước 6 (từ dấu { đến dấu }).

Bấm Chạy Thử Nghiệm & Tận Hưởng Thành Quả

Kích hoạt lần đầu tiên bằng tay và ngắm nhìn cỗ máy tự động làm việc hoàn toàn từ A-Z.

  1. Trên kho mã nguồn GitHub của bạn, bấm vào tab Actions.
  2. Ở cột bên trái, bấm chọn quy trình: 🤖 Tự Động Viết & Đăng Bài Blogger Chuẩn SEO.
  3. Bấm nút Run workflow ở góc phải ➔ Chọn nhánh main ➔ Bấm nút màu xanh Run workflow.
  4. Chờ khoảng 1-2 phút:
    • Vòng tròn chuyển sang màu xanh lá cây (Success ✓).
    • Telegram báo thông báo bài viết đã được lên lịch thành công!
    • Google Sheets: dòng đề tài tự động đổi sang màu xanh lá cây kèm link bài viết.
    • Blogger: bài viết đã sẵn sàng trong mục Đã lên lịch với ảnh Thumbnail YouTube Doanh Nhân chuẩn mực.
    • Đến giờ xuất bản, robot quét bài Live sẽ tự động bắn Indexing lên Google Search Console ngay tức khắc!
